# 🌌 AetherOS - Next-Gen Neural Practice & Task Management System

A high-performance, glassmorphic **MERN Stack** application designed for sub-millisecond data synchronization and immersive 3D practice management. This project features a cutting-edge **React 19** frontend, real-time neural objective tracking, and a robust **Vite 8** architecture optimized for deep-learning researchers and developers.

## ✨ Key Features

### 🧠 Neural Command Center

  * **Immersive 3D Matrix:** Integrated **Three.js** and **React Three Fiber** visualizations for real-time data orientation.
  * **Nexus Tasker:** A high-fidelity objective management system with instant MongoDB persistence and state-syncing.
  * **Quantum Analytics:** Deep-dive metrics portal tracking system throughput, neural load, and sync integrity.
  * **Phase 3 Aesthetics:** Custom-engineered Tailwind v4 glassmorphism with dynamic noise grain and "Emerald Glow" UI shaders.

### 🛡️ Secure Mesh Protocols

  * **JWT Handshake:** Secure token-based authentication ensuring encrypted links between the client and the neural core.
  * **Dynamic CORS Firewall:** Advanced backend security allowing seamless communication across Vercel cloud subdomains.
  * **Persistence Layer:** Robust MongoDB Atlas integration for non-volatile storage of mission-critical data.
  * **Edge-Ready Middleware:** Optimized for modern cloud environments with strict environment variable injection.

## 🛠️ Local Setup Instructions

### 1\. Prerequisites

  * Node.js (v20 or higher)
  * MongoDB Atlas account
  * Git

### 2\. Clone the Repository

```bash
git clone https://github.com/islamrakibul9274/aether-os.git
cd aether-os
```

### 3\. Install Dependencies

You must install dependencies for both the core and the client mesh:

```bash
# Root directory
npm install

# Client directory
cd client
npm install
```

### 4\. Environment Configuration

Create a `.env` file in the **server** directory:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_neural_handshake_secret
PORT=5001
```

Create a `.env` file in the **client** directory:

```env
VITE_API_URL=http://localhost:5001
```

### 5\. Start the Neural Core

```bash
# Run backend (from server folder)
npm run dev

# Run frontend (from client folder)
npm run dev
```
